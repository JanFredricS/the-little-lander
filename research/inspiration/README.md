# Style reference images (from Jan)

These are the user-supplied inspiration images. The in-game art is 100%
procedurally generated; these define the *targets* the generators and
palettes are tuned toward.

| Image | What it informs |
|---|---|
| `apollo-csm-lem-cartoon.jpeg` | Vessel silhouettes: CSM cone + cylinder + engine bell, LEM with gold descent stage, angular ascent stage, spindly legs with pad feet. Keep the friendly, slightly cartoonish proportions — readable at small sprite sizes. Gold/orange foil vs grey metal is the key color split. |
| `lem-landing-illustration.jpeg` | Thruster exhaust look: soft orange/amber pulse plume under the LEM; two-stage read (hovering vs landed on legs). Landing pose reference. |
| `pixel-space-station-deck.jpeg` | Map 1 hangar theme: cool steel blue/periwinkle palette, chunky riveted beams and pillars, hanging rack modules, planet glow through openings, small amber screen accents. Dark-outline, high-contrast pixel style. |
| `pixel-astronaut-cabin.jpeg` | Cutscene still quality bar: deep navy/teal interior, warm gold light pool, big window framing an awe view, single character silhouette. This is the tone for the cockpit/briefing/outpost cutscenes — limited palette, strong warm-vs-cool light. |
| `pixel-jungle-mech-island.jpeg` | Overgrown-tech look (abandoned outpost, ruins in maps 7–8): mossy greens over dark brown machinery, teal sky, bright puffy clouds, hanging vine strands. Cluster-dither foliage technique. |
| `floating-islands-sunset-dragons.jpeg` | Map 3 mood: golden-haze backlight, waterfalls off floating islands, hanging vine/root strands, distant winged creatures as dark silhouettes, layered mist parallax. |
| `floating-islands-sky-moon.jpeg` | Map 3 daytime backdrop: many island sizes receding into bright haze, pale moon/planet in sky, cool blue-white palette for far parallax layers vs saturated green/brown near layers. |
